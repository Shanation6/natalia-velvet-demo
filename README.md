# Наталья — косметология Москва

Статическая демонстрационная концепция. Без сервера, сбора персональных данных, оплаты и автоматической записи. Кнопки открывают личный Telegram. Для GitHub Pages достаточно опубликовать корень репозитория.

## Источники и границы фактов

Проверено 8 ноября 2026 года через публичную HTML-страницу Telegram (`urllib.request`).

- [Профиль Натальи](https://t.me/sugaring_velvet_moskva): публичное имя «👩‍⚕️ Наталья Ваш косметолог Москва м.Верхние Лихоборы»; bio: «Косметолог 🇷🇺Москва телеграм канал 👇 https://t.me/sugaring_moskva Хобби 👉 https://t.me/Aquarium_house».
- [Публичный профессиональный канал](https://t.me/s/sugaring_moskva), прямо связанный из bio: автор называет себя неинвазивным косметологом, кабинет NS; упоминает эндосферу для лица и тела, химические пилинги, депиляцию и шугаринг. Эти названия использованы без обещаний результатов, цен и медицинских рекомендаций. Адрес и телефон с канала намеренно не публикуются: перед запуском требуется согласование актуальности.
- [Личный hobby-канал](https://t.me/Aquarium_house) не использован как профессиональное подтверждение.
- Подарочные сертификаты — тема из первоначального задания, наличие и условия публично не подтверждены. На странице явно обозначены концепцией.

## Работа интерфейса

Навигация ведёт к секциям. Три темы обращения переключают пояснение с `aria-pressed` и `aria-live`; все темы дополнительно доступны в нативном раскрывающемся списке, в том числе без JavaScript. FAQ — нативные `details`. Видимый клавиатурный фокус, ссылка пропуска навигации, reduced-motion. Мобильная композиция заменяет колонки вертикальной последовательностью. Данные не сохраняются, формы отсутствуют.

Локальный запуск: `python -m http.server 4201` из папки проекта. QA-артефакты могут находиться в игнорируемой папке `.work/`.
